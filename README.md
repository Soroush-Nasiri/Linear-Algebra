# Linear Algebra

This directory contains projects and implementations for the Linear Algebra course.

## Projects

*   **[PageRank and HITS Algorithms](./PageRank%20and%20HITS)**: C++ implementations of PageRank and HITS (Hyperlink-Induced Topic Search) algorithms for network analysis, comparing iterative results with Sparse SVD computed using Python.
*   **[Image Compression using SVD](./Image%20Compression)**: Low-rank image compression demonstrating Singular Value Decomposition (SVD) and energy compaction on image matrices using Python.
